# 研究问题与学段定位

## 1. 工作版研究问题

初中语文教材如何通过生命母题的系统建构，实现小学“情感启蒙”向高中“文化思辨”的过渡，并促进 13 岁学生核心素养的发展？

这句话同时锁定五个研究维度：

1. **教材研究**：以统编教材为对象，而非单篇课例技巧。
2. **学段衔接**：小学—初中—高中的纵向定位。
3. **母题理论**：从题材标签上升到生命主题与存在问题。
4. **核心素养**：把母题教学接到可观察的素养生成。
5. **发展心理学窗口**：以 13 岁前后的自我意识形成期为关键学段。

## 2. 纵向定位（总论）

| 学段 | 核心任务 | 阅读形态 | 价值坐标 |
|------|----------|----------|----------|
| 小学 | 语言感知、阅读兴趣、情感启蒙 | 感受性阅读 | 喜欢、害怕、温暖、勇敢（直觉层） |
| 初中 | 主题建构、价值辨析、自我意识形成 | 过渡性阅读：从儿童阅读走向公民阅读 | 自由/规则、勇气/冲动、归属/漂泊（辨析层） |
| 高中 | 文化反思、思辨能力、审美判断 | 批判性与文化性阅读 | 个人与国家、传统与现代、历史与价值（判断层） |

### 可验证假设

> 初中语文的独特任务，是完成“生命主题的初次系统化”。

小学阶段学生可以“感受春天”“喜欢母亲”“觉得勇敢很好”；  
初中阶段需要追问：为什么人会想家？自由与规则如何冲突？成长为何伴随失去？勇敢与冲动有何区别？  
高中阶段再进入个人与国家、传统与现代、历史与文化的价值判断。

## 3. 三层论文结构

### 第一层：纵向定位

回答：初中语文在 12 年语文教育链条中承担什么独特任务？

可用理论：

- 王荣生：语文课程内容与学段任务
- 姚斯：期待视野（不同年龄读者的前理解）
- 维果茨基：最近发展区（13 岁可进入价值辨析）

### 第二层：初中课文母题分类

不要按文体分类，而按生命主题分类，形成“初中语文主题课程图谱”。

### 第三层：母题递进关系

例如：

- 自然风景 → 生态意识 → 文化认同 → 社会责任
- 自由 → 规则 → 责任 → 担当

这构成“核心素养生成链”，也是最有学术增量的部分。

## 4. 理论组合（够学术、不过载）

| 理论 | 用途 | 使用边界 |
|------|------|----------|
| 诺思洛普·弗莱《批评的解剖》 | 母题、原型、文学整体观 | 只取原型/母题相关部分 |
| 姚斯 | 不同年龄的阅读期待 | 服务学段衔接论证 |
| 伊瑟尔 | 读者如何参与意义生成 | 解释课堂中的意义建构 |
| 维果茨基 | 13 岁认知与最近发展区 | 证明初中可做价值辨析 |
| 王荣生 | 语文课程定位 | 把研究锚定在课程论而非课例秀 |
| 孙绍振 | 文本细读方法 | 保证母题不脱离文本 |
| 李泽厚《美的历程》 | 中国审美与文化积淀 | 连接母题与文化传统 |
| C. Wright Mills《社会学的想象力》 | 个体经验—社会结构转换 | 把“想家”提升为“归属与社会结构” |

暂缓：巴特勒、福柯等原典。先把课程框架立住，再按需引入。

## 6. 表达纪律

课堂可以说：“《西游记》其实是在讨论自由。”  
论文应写成：

> 本文将《西游记》中的“大闹天宫—受箍—西天取经”叙事链条视为“自由—规则—责任”母题的递进过程，并据此探讨初中阶段学生对自由观念的认知建构。

原则：少用省略号式递进修辞；多用“概念—定义—例证—推论”。
