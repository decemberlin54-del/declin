# 学习《寓言四则》·短故事，大镜子

**第八、九课时 · 子任务五：精读《寓言四则》，归纳寓言特点，积累文言，探究寓意与情节设计**

---

## 【课时目标】

1. 通过阅读四则寓言，归纳寓言的文体特点，理解各则寓意。
2. 借助注释疏通《穿井得一人》《杞人忧天》，积累重点文言词语。
3. 分析寓意与情节设计的关系，认识寓言情节与寓意之间的关系，探究“杞人忧天”的多种理解。

---

## 【评价任务】

1. 完成“寓言档案卡”，准确概括四则寓言的情节与寓意，归纳寓言文体特点。（检测目标1）
2. 借助注释准确翻译《穿井得一人》《杞人忧天》重点语句，解释“闻、传、道、亡”等文言词语。（检测目标2）
3. 结合具体情节分析寓意如何产生，说出“杞人忧天”的至少两种理解，并能联系生活谈启示。（检测目标3）

## 【学习过程】

**课前热身：** 在前面的学习中，我们读过神魔斗法的奇幻、童话的夸张反讽、神话的创世想象。今天，我们要读四则“短故事”——它们篇幅极短，却像一面面“大镜子”，照见人心与社会。请你想一想：为什么《赫耳墨斯和雕像者》里，雕像者一句“白送”，会让赫耳墨斯难堪？为什么《穿井得一人》里，一句“吾穿井得一人”会在国都传开？带着这些问题，走进寓言的世界。

### 学习任务三：疏通文言，积累词语，探究“杞人忧天”的多种理解

1. 借助注释，朗读《穿井得一人》《杞人忧天》，读准字音、停顿。（指向目标2）

2. 完成学习任务单三，解释加点词，翻译重点句。（检测目标2）

**学习任务单三：**

| 语句 | 加点词 | 释义 |
|------|--------|------|
| 有**闻**而传之者 | 闻 | |
| 国人**道**之 | 道 | |
| **闻**之于宋君 | 闻 | |
| 身亡所**寄** | 亡 | |
| 因往**晓**之 | 晓 | |
| 其人**舍然**大喜 | 舍然 | |

**重点句翻译：**

（1）得一人之使，非得一人于井中也。

（2）求闻之若此，不若无闻也。

（3）若屈伸呼吸，终日在天中行止，奈何忧崩坠乎？

3. **多种理解探究：** 《杞人忧天》通常讽刺“不必要的担忧”，但也有人读出“对未知自然的忧患意识”。请结合原文完成学习任务单四。（指向目标3、检测目标3）
