# 推进路线图（研究工程化）

## 原则

每次只推进一个明确任务。不要同时做五件事。

## 阶段划分

### 第 0 步（已完成）

- 压缩为一句话研究问题
- 明确核心假设：初中 = 生命主题的初次系统化
- 区分 L1/L2/L3，避免沦为中考分类翻版

### 第 1 步：教材总表（进行中）

建立 Excel/CSV，字段建议：

| 字段 | 说明 |
|------|------|
| grade | 学段册次（七上/七下…） |
| unit | 单元 |
| title | 课文 |
| author | 作者（可空） |
| genre | 文体 |
| required | 精读/略读 |
| motif_l1 | 题材层直觉标签 |
| motif_l2_primary | 一级母题（主） |
| motif_l2_secondary | 一级母题（次） |
| motif_l3_question | 存在层问题 |
| notes | 备注 |

先求全，再求准。当前已完成七年级初稿。

### 第 2 步：锁定 12 个一级母题

用七年级总表做覆盖率检验：

- 每篇课文至少挂 1 个一级母题
- 每个一级母题至少覆盖 3 篇以上课文
- 高度重叠的母题合并；过窄的降为二级

### 第 3 步：《西游记》示范案例

形成可发表样板：把“大闹天宫—受箍—西天取经”写成“自由—规则—责任”母题链。

### 第 4 步：第一篇论文提纲 → 成稿

题目方向：《初中语文在 12 年语文课程中的过渡定位》  
篇幅控制：8000–12000 字。

### 第 5 步：项目申报框架

为读博准备：问题—综述—框架—方法—预期成果—论文群。

## 近期作业顺序

1. 修订七年级母题标注（学术化修正）
2. 补八年级、九年级总表
3. 写《西游记》案例 3000 字样章

## 协作方式

- 你提供：教学现场直觉、课堂反馈、文本细读感受
- 助手提供：分类逻辑修正、学术语言转写、框架一致性检查
- 共同产出：可论证、可分类、可实施、可评价的课程研究框架
