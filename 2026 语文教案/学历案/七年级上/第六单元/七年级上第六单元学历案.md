## 一、你敢挑战吗？

进入中学后，有的同学写作文只会记流水账，有的同学则天马行空、脱离题意；读童话寓言时，也只记得热闹情节，说不清“想象”和“真实”的关系。

假如你是班级“文学部落”创意小组的成员，请结合本单元童话、神话、寓言和神魔小说片段，为一位写作困难的同学创作一份 **300 字左右的创意小故事（或分镜脚本）**，并附 **100 字创作说明**：说明你如何运用联想与想象，做到**既有趣味，又有依据，还能传递积极的价值追求**。

## 三、你将学会什么

1. 通过阅读《小圣施威降大圣》，梳理情节脉络、分析孙悟空与二郎神的人物特点，理解神魔小说中夸张想象的作用，发展阅读与概括能力。

2. 通过精读《皇帝的新装》，品味夸张、反复等修辞，分析“新装”的象征意义与群体沉默的原因，理解童话讽刺艺术，发展审美鉴赏与批判思维能力。

3. 通过自读《女娲造人》，概括神话情节，分析联想与想象的生发路径，理解中华民族创世神话的文化内涵，发展文化理解与联想能力。

4. 通过《寓言四则》学习，准确概括寓意，联系生活进行合理联想，区分“想象”与“臆断”，发展思辨与迁移能力。

5. 通过写作训练与文学部落活动，运用联想与想象完成创意表达，能说明“想象有据、联想合理、主题有温度”，发展语言运用与创意表达能力。

6. 通过《西游记》整本书阅读导读，了解章回体小说特点，初步掌握跳读、批注、情节链梳理等名著阅读方法。

## 四、给你支招

### 1. 为何学

本单元是七年级上册“活动·探究”之外的**文学想象单元**，对应课标“发展形象思维能力”“提高语言表现与创造能力”的要求。七年级学生想象力活跃，但常把“想象”误解为“胡编”；读童话寓言时易停留在情节热闹，难以概括寓意、联系现实。

本单元通过童话、神话、寓言、神魔小说片段的组合，帮助学生建立三层认识：

- **想象要有物**：从具体形象、细节出发（如“新装”“黄土”“筋斗云”）。
- **想象要有思**：服务于主题与情感（如讽刺、警示、赞美）。
- **想象要有度**：联想合理，能回到真实生活（如寓言启示、写作表达）。

### 2. 如何学

（1）**批注阅读法**：圈画描写想象、夸张、对比的语句，标注“写了什么—怎样写—为什么这样写”。

（2）**比较阅读法**：比较《皇帝的新装》与《寓言四则》中“假象”的不同；比较童话、神话、寓言中“想象”的功能差异。

（3）**情境体验法**：分角色朗读《皇帝的新装》；为《女娲造人》配画面描述；用现代情境改写寓言结局。

（4）**读写结合法**：每篇课文学完后，写 50–80 字“联想句”或“寓意句”；单元末完成创意故事。

（5）**合作探究法**：小组合作完成“寓意卡片”“想象路径图”“文学部落作品展”。

### 3. 还可以从哪里学

- 安徒生《丑小鸭》《海的女儿》；袁珂《中国神话传说》
- 电影《大闹天宫》《哪吒之魔童降世》片段（比较想象呈现）
- 漫画分镜入门资料；《西游记》连环画或有声书
- 课外古诗词：刘禹锡《秋词》、陆游《十一月四日风雨大作》等

### 第一课时：单元导学 +《小圣施威降大圣》整体感知

**【课时目标】**

1. 浏览单元学历案与教材单元导语，整体感知本单元学习目标、挑战任务与学习路径。

**【评价任务】**

1. 说出本单元核心挑战任务及需要做的准备。（检测目标 1）
2. 用简洁语言概括课文情节，找出一处体现“想象”的描写。（检测目标 2）

**【学习过程】**

**课前热身**

《西游记》里，孙悟空一个筋斗十万八千里，二郎神会七十二变，天庭神将各显神通——这些情节若放在现实里不可能，却能让读者看得入迷。今天走进“文学部落”，看看作家是如何用联想与想象，把神魔世界写得既荒诞又合理。

**学习任务一：学习单元概览，明确挑战任务**

1. 自行阅读单元学历案“单元概览”部分，圈点挑战任务、学习目标、课时安排。（指向目标 1）
2. 同伴交流：说说“为同学创作联想与想象故事”这一任务，你打算从哪篇课文汲取灵感。（检测目标 1）
3. 阅读教材单元导语，说说本单元与第五单元（人与动物）在学习重点上有何不同。（指向目标 1）

**学习任务二：速读课文，感知情节与想象**

1. 默读《小圣施威降大圣》，按“孙悟空变化—二郎神应对—大战升级”梳理情节。（指向目标 2）
2. 勾画一处你最觉得“想象奇特”的描写，批注：作者用了什么写法？（检测目标 2）
3. 小组交流：这种夸张想象对表现孙悟空形象有什么作用？（检测目标 2）

**【课堂小结】**

本单元重点是学会**有依据的联想与想象**；本课神魔片段让我们看到，想象可以服务于人物塑造与情节推进。

### 第二课时：精读《皇帝的新装》（一）——情节与人物

**【课时目标】**

1. 梳理童话情节发展脉络，分析皇帝、大臣、小孩三类人物的不同表现。
2. 找出文中反复出现的细节，初步理解“新装”的象征意义。

**【评价任务】**

1. 完成情节发展图（开端—发展—高潮—结局）。（检测目标 1）
2. 结合文本语句，说明皇帝“爱新装”的性格特点。（检测目标 1）

**【学习过程】**

**课前热身**

“看不见新装”的人，真的是愚蠢吗？还是另有原因？今天我们一起走进安徒生的童话世界。

**学习任务一：梳理情节，初识人物**

1. 速读全文，填写情节发展图。（指向目标 1）
2. 分角色朗读关键段落（皇帝看布、游行大典），体会语气。（指向目标 1）
3. 小组讨论：大臣们明明看不见，为什么却纷纷夸赞？（检测目标 1）

**学习任务二：品味细节，理解象征**

1. 圈画“新装”“织布机”“赤身游行”等关键词句，说说它们可能象征什么。（指向目标 2）
2. 思考：这是一个怎样的“想象”？它与《小圣施威降大圣》中的想象有何不同？（检测目标 2）

**【课堂小结】**

童话的想象不仅为了有趣，更为了揭示人性与社会现象；《皇帝的新装》用“不存在的新装”讽刺虚伪与盲从。

### 第四课时：自读《女娲造人》

**【课时目标】**

1. 概括神话情节，梳理女娲造人的过程。

**【评价任务】**

1. 用流程图呈现“女娲造人”的过程。（检测目标 1）

**【学习过程】**

**课前热身**

**学习任务一：自读梳理**

1. 默读课文，完成造人过程流程图：揉土造人—藤条洒泥—婚配繁衍。（指向目标 1）

**【学习过程】**

**课前热身**

想象力是翅膀，但翅膀需要风的方向。写作中的想象，不是脱离题目的“乱想”。

**学习任务一：回顾归纳**

1. 小组回顾四篇课文 + 寓言，填写“想象案例卡”：

| 篇目 | 想象/联想点 | 是否合理 | 理由 |
|------|-------------|----------|------|
| 小圣施威降大圣 | | | |
| 皇帝的新装 | | | |
| 女娲造人 | | | |
| 寓言四则 | | | |

2. 全班归纳“合理想象”标准：有触发点、有逻辑、有主题、有情感温度。（检测目标 1）

**学习任务二：技法训练**

1. 学习三种路径，各写 1 个练习句（50 字）：
   - 由物及物：从一个事物联想到另一个事物
   - 由物及理：由具体事物上升到道理
   - 由物及情：借事物抒发情感

2. 同伴互评：是否“联想自然、想象有物”。（检测目标 2）

### 第九课时：写作实践《发挥联想和想象》（二）

**【课时目标】**

1. 完成 300 字左右创意小故事（或分镜脚本），回应单元挑战任务。
2. 撰写 100 字创作说明，阐释联想与想象的运用。

**【评价任务】**

1. 完成创意作品，符合“联想合理、想象有物、主题积极”。（检测目标 1）
2. 完成创作说明，能指出具体文本依据。（检测目标 2）

**【学习过程】**

**课前热身**

今天，把你在本单元学到的“想象之力”，真正用到创作里。

**学习任务一：构思与写作**

1. 确定创作对象：为“写作困难的同学”创作，明确要帮助的困惑（只会流水账/想象过度/不敢写）。 （指向目标 1）
2. 选择灵感来源：从本单元任一篇课文中提取 1 个意象或主题（如“说真话”“造人”“骄傲与自知”等）。（指向目标 1）
3. 独立写作 300 字左右；或完成 6–8 格分镜脚本。（检测目标 1）

**学习任务二：创作说明与评价**

1. 写 100 字创作说明：我用了什么联想路径？想象依据来自哪篇课文？（检测目标 2）
2. 小组互评，使用评价量表（见下表）。（检测目标 1、2）

### 第十课时：文学部落 + 单元小结 +《西游记》导读

**【课时目标】**

1. 在“文学部落”活动中展示创意作品，发展口头表达与互评能力。
2. 梳理本单元知识，完成单元小结。
3. 了解《西游记》整本书阅读要求，掌握基本阅读方法。

**【评价任务】**

1. 清晰展示创意作品并回答提问。（检测目标 1）
2. 说出本单元三种文体（童话/神话/寓言）的想象特点。（检测目标 2）
3. 说出《西游记》整本书阅读的 2 种方法。（检测目标 3）

**【学习过程】**

**课前热身**

文学部落开张了！今天，我们把童话、神话、寓言和神魔小说里学到的想象力，变成自己的作品。

**学习任务一：文学部落展示**

1. 小组推选作品，作者展示 3 分钟：故事/脚本 + 创作说明。（指向目标 1）
2. 听众提问互动，作者回应。（检测目标 1）
3. 评选“最佳联想奖”“最佳创意奖”“最佳表达奖”。（检测目标 1）

**学习任务二：单元梳理**

1. 完成单元小结表：

| 文体 | 代表篇目 | 想象/联想特点 | 我学到的方法 |
|------|----------|---------------|--------------|
| 童话 | 皇帝的新装 | | |
| 神话 | 女娲造人 | | |
| 寓言 | 寓言四则 | | |
| 神魔小说 | 小圣施威降大圣 | | |

2. 用一句话回答单元核心问题：**怎样的联想与想象才是“好的”？**（检测目标 2）

**学习任务三：《西游记》整本书阅读导读**

1. 阅读教材名著导读，了解作者、体裁、版本特点。（指向目标 3）
2. 学习阅读方法：精读与跳读结合、批注人物、梳理“取经团队”关系、关注“神魔想象”服务主题。（检测目标 3）
3. 布置整本书阅读计划：建议 4 周读完，每周完成 1 次阅读单。（检测目标 3）

**【课堂小结】**

本单元让我们看见：联想与想象是语文创造力的核心；童话教我们会心一笑中的批判，神话教我们追问起源，寓言教我们明辨是非，神魔小说教我们驾驭宏大想象——而写作，就是把这一切变成自己的语言。

## 六、单元作业设计

### 阅读

1. 阅读安徒生童话《丑小鸭》或《海的女儿》，写 150 字阅读札记：作者如何运用想象？
2. 阅读袁珂《中国神话传说》中另一则创世或英雄神话，比较与《女娲造人》的异同。

### 语言运用

1. 仿写：借鉴《皇帝的新装》反复式描写，写 80 字片段。
2. 改写：将《穿井得一人》改写为现代校园“谣言传播”小故事，100 字。

### 写作

**题目**：《那一次，我想象的翅膀带我飞到了……》

要求：
- 运用联想与想象，有具体触发物
- 写出情感或思考，不少于 500 字
- 忌抄袭，不用真实校名、人名

### 整本书阅读（暑假/学期延续）

- 完成《西游记》阅读计划表
- 摘抄 5 处“神魔想象”描写并批注
- 绘制“取经团队”人物关系图

## 七、学后反思

1. 本单元三种文体（童话、神话、寓言）的“想象”有何不同？你最喜欢哪一种？为什么？

2. 在“文学部落”创作中，你遇到的最大困难是什么？你是如何解决的？

3. 为什么说“联想与想象”不是“胡编乱造”？请结合一篇课文说明。

4. 读完《西游记》导读后，你对整本书阅读有什么计划或担心？
