# 初中语文母题研究

> 个人研究工作库：把“文学直觉”固化为可论证、可分类、可实施、可评价的课程研究框架。

## 一句话研究问题

初中语文教材如何通过生命母题的系统建构，实现小学“情感启蒙”向高中“文化思辨”的过渡，并促进 13 岁学生核心素养的发展？

## 核心假设

初中语文的核心任务不是知识点的线性叠加，而是**生命主题的初次系统化**。
